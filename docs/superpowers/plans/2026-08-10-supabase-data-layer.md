# Dictionary Supabase Data Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace browser-only dictionary persistence with a secure Supabase-backed shared catalog, permanent owner account, and isolated anonymous guest state, then deploy the frontend on the existing Vercel project.

**Architecture:** Keep the current static React application and add a small build step that emits public Supabase runtime configuration. Store canonical words in `dictionary_entries`, store per-user collection and explanation state in `user_word_state`, and enforce all boundaries with RLS. Use Supabase Auth magic-link login for the permanent owner and anonymous sign-in for guests.

**Tech Stack:** Static React 18, Babel standalone, Supabase JavaScript `2.112.2`, Supabase Auth/Postgres/RLS, Node.js 24 build scripts and built-in test runner, Vercel static hosting.

- [ ] **Step 3: Write the migration**

The migration must:

```sql
create table public.dictionary_entries (
  id uuid primary key default gen_random_uuid(),
  word text not null,
  part_of_speech text not null,
  cefr_level text not null default 'UNKNOWN'
    check (cefr_level in ('A1','A2','B1','B2','C1','C2','UNKNOWN')),
  definition text not null default '',
  definition_url text not null default '',
  audio_url text not null default '',
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create unique index dictionary_entries_word_pos_key
on public.dictionary_entries (lower(word), lower(part_of_speech));

create table public.user_word_state (
  user_id uuid not null references auth.users(id) on delete cascade,
  entry_id uuid not null references public.dictionary_entries(id) on delete cascade,
  collect_count integer not null default 0 check (collect_count >= 0),
  ai_explanation jsonb,
  updated_at timestamptz not null default now(),
  primary key (user_id, entry_id)
);
```

Add a `security invoker` timestamp trigger function, enable RLS, revoke default public access, grant the necessary `SELECT/INSERT/UPDATE/DELETE` privileges to `authenticated`, and create these policies:

```sql
-- Catalog read
to authenticated using (true)

-- Catalog owner writes
to authenticated
using ((select auth.jwt()->'app_metadata'->>'role') = 'owner')
with check ((select auth.jwt()->'app_metadata'->>'role') = 'owner')

-- Per-user state
to authenticated
using ((select auth.uid()) = user_id)
with check ((select auth.uid()) = user_id)
```

Insert every row from `seed.jsx` idempotently with `on conflict` against normalized word and part of speech.
